# Agent Rules

Shared rules for Claude Code and Codex. This file lives at
`~/agents/AGENTS.md`, regardless of the current directory. Read
`~/agents/Startup.md` before any work. Then read these guides when applicable,
in order:

1. `~/agents/Git.md` when running in a Git repository.
2. `~/agents/Dev.md` for software development or code review.
3. `~/agents/Plans.md` when working on a plan file.
4. `~/agents/Memory.md` when using Rumi beyond the startup recall.

Stop if a guide required for the current task is missing.

Precedence: the user's instructions, then the project's root `AGENTS.md`
when working in a project, then these files.
